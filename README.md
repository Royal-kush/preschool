# موقع روضة رويال كوش

## التشغيل محلياً
افتح `index.html` بالمتصفح مباشرة، أو شغّل خادماً بسيطاً:
`python3 -m http.server 8000` ثم افتح `http://localhost:8000`.
الموقع يعمل دون إنترنت (خط Cairo يتحول تلقائياً إلى Tahoma عند عدم توفره).

## تغيير الصور
ضع الصور في `assets/images/` بهذه الأسماء:
- `hero.jpg` صورة الغلاف (تظهر داخل الإطار الدائري، وإن لم توجد يظهر رسم الشمس).
- `about.jpg` قسم من نحن، و`environment.jpg` قسم البيئة.
- صور المعرض: ضعها في `assets/images/gallery/` وأضفها في `js/main.js` داخل `GALLERY` بالشكل:
  `{src:"assets/images/gallery/1.jpg", alt:"وصف الصورة"}`.
لصورة المشاركة (Open Graph) أزل التعليق في `<head>` داخل `index.html`.

## تغيير الألوان
في أول `css/style.css` داخل `:root` (`--o` البرتقالي، `--od` الداكن، `--cream`، `--y`، `--m`).

## الهاتف وواتساب والعنوان وكلمة الإدارة
كلها في أعلى `js/main.js` داخل `CONFIG` و`MANAGEMENT_MESSAGE`. عند إضافة رقم واتساب يظهر زر التواصل المباشر تلقائياً.
